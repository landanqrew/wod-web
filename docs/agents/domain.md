# Domain Docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read the ADRs under `docs/adr/` that affect the area being changed.
- If either source does not exist, proceed silently.

## Use the glossary vocabulary

Use domain terms as defined in `CONTEXT.md` in code, tests, issues, and documentation. Avoid synonyms that the glossary explicitly rejects.

If a needed concept is missing, reconsider whether it belongs in the existing language or note the gap for a future documentation discussion.

## Flag ADR conflicts

Surface any proposed change that contradicts an existing ADR instead of silently overriding the recorded decision.
